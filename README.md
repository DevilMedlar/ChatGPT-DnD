# ChatGPT-DnD

A persistent chat-driven adult fantasy RPG campaign played with ChatGPT.

## Source of truth

Campaign continuity lives in this repository. Before continuing a campaign, read the active save and supporting state files. After meaningful character, inventory, quest, relationship, world, or scene changes, update the relevant files.

## Campaign files

- `GAME_MASTER_RULES.md` - campaign mechanics, continuity rules, and content boundaries.
- `saves/active_game.json` - compact machine-readable state for the active campaign.
- `saves/character_sheet.md` - human-readable player character sheet.
- `saves/world_state.md` - important locations, NPCs, factions, relationships, quests, and unresolved threads.
- `saves/session_log.md` - chronological campaign summaries and checkpoints.
- `art/art_log.md` - canonical visual details and scene-art notes so recurring characters stay visually consistent.
