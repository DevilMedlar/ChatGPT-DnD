# Routine Item Base Prices

This file is the authoritative campaign-local data reference for **routine/basic repeat-good classification** and each classified item's recurring **Base Price**.

The shared rules for establishing, using, changing, staging, reconciling, and verifying recurring Base Prices are owned by `../GAME_MASTER_RULES.md`. This file does not redefine those rules.

The routine/basic classification here is a **campaign shopping classification**, not the same thing as an official D&D rarity category such as Common, Uncommon, Rare, or another rules-defined rarity.

Each entry must identify the exact item under the campaign's adopted rules/reference context before the classification and recurring Base Price are established through the shared workflow.
