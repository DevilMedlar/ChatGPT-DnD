# Campaign 1 Rules

This file is the canonical persistent rule layer for rules, overrides, exceptional premises, and operating instructions that apply specifically to Campaign 1.

Campaign 1 inherits the reusable rules under `../../../Rule/`. This file contains only the **Campaign 1-specific delta** from those reusable rules.

Do not duplicate unchanged repository-wide rules here merely for convenience.

Do not store ordinary Campaign 1 character, NPC, relationship, inventory, world, quest, shop, session, advancement, art, or other state facts here. Those facts remain in their assigned campaign state files.

When the player explicitly establishes, changes, or rescinds a persistent Campaign 1-specific rule, update this file so future sessions can recover that rule from the repository rather than chat memory.

Rule priority and scope are defined in `../../../Rule/RULE_AUTHORITY_AND_HIERARCHY.md`. Campaign isolation is defined in `../../../Rule/CANON_HISTORY_AND_CAMPAIGN_ISOLATION.md`.
