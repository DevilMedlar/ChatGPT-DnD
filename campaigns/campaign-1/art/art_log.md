# Art Continuity Log — Campaign 1

This file is the canonical visual index for Campaign 1.

## Image Workflow

- Not every scene needs an image.
- When a scene genuinely deserves one, normal narration and gameplay choices come first, then the response ends with `Make image? Yes / No`.
- `Yes` means generate the image before resolving gameplay choices for that scene. After the image is shown, wait for the player's gameplay input.
- `No` means skip image generation and parse any remaining text in the same reply as gameplay input, including compact replies such as `No, A, 1, E) ...`.
- Generated images may include adult sensuality or nudity when permitted by the image system.
- Every character depicted nude or in sexualized presentation must be explicitly 18+.
- Textual campaign canon wins over accidental image inconsistencies unless the player explicitly adopts the visual variation.
- Generated image files are not automatically repository canon. Record a repository path only after the file actually exists there.
