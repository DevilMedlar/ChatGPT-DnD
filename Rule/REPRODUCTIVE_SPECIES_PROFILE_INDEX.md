# Reproductive Species Profile Index

## Purpose

This file is the navigation index for the repository's current reproductive-biology and crossbreeding rules.

The former `REPRODUCTIVE_SPECIES_COMPLETE_PROFILES_BATCH_2.md` through `REPRODUCTIVE_SPECIES_COMPLETE_PROFILES_BATCH_17.md` files have been deleted and are no longer current-branch authorities.

## Current file order

Use the surviving files in this order:

1. `REPRODUCTION_AND_LINEAGE.md` — global eligibility, male/female reproductive requirements, adoption separation, carrying-parent development, birth-safe hybrid development, and lineage framework
2. `REPRODUCTIVE_SPECIES_CANDIDATE_CATALOG.md` — authoritative global active whitelist of selectable reproductive species and families
3. `REPRODUCTIVE_SPECIES_CORE_SELECTION.md` — compact character-creation presentation of the same active whitelist; it does not expand the catalog
4. `REPRODUCTIVE_FERTILIZATION_COMPATIBILITY.md` — fertilization-path and directional-compatibility rules
5. `REPRODUCTIVE_SPECIES_PROFILES.md` — species-profile schema and research discipline
6. `REPRODUCTIVE_SPECIES_COMPLETE_PROFILES.md` — surviving reusable biological profiles and background research

## Authority order

When reproductive files overlap:

1. the player's newest explicit instruction
2. an applicable campaign-specific override
3. `REPRODUCTIVE_SPECIES_CANDIDATE_CATALOG.md` for global selectability
4. `REPRODUCTION_AND_LINEAGE.md` and `REPRODUCTIVE_FERTILIZATION_COMPATIBILITY.md` for global reproductive operation
5. a specific surviving profile in `REPRODUCTIVE_SPECIES_COMPLETE_PROFILES.md`
6. the general schema or research material in `REPRODUCTIVE_SPECIES_PROFILES.md`

`REPRODUCTIVE_SPECIES_CORE_SELECTION.md` is presentation guidance only. It must mirror the active candidate catalog and cannot independently restore a removed species.

## Selectability versus biological reference

A species may still appear in a surviving research/profile file without being selectable.

- The active whitelist controls ordinary global selection.
- An omitted species is not restored merely because an older or broader profile describes its biology.
- A removed species may return only through the player's newer explicit instruction or an applicable campaign-specific override.
- Historical Git content is not current-branch authority.

## Directional compatibility

Always evaluate reproductive direction separately when it matters:

- male Species A + female Species B
- male Species B + female Species A

The female contributor normally determines live-bearing, egg-laying, or another established development route. The male contribution must still be capable of reaching and fertilizing the egg through a valid biological pathway.

## Birth viability and adult fertility

Keep these as separate questions:

- can the parent pairing conceive?
- can the offspring develop and be born or hatch?
- is the resulting adult hybrid fertile?

Evidence for one does not automatically prove the others.

## Future maintenance

When the player approves a new species:

- add or revise its active catalog row
- place concise reusable biology in an existing surviving profile file when needed
- keep the core-selection file synchronized
- update this index only when the file structure or authority order changes
